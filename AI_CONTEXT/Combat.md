# Combat context

Tutorial combat is implemented by `YourQuestTutorialCombat`/`YourQuestTutorialEnemy`; production enemies use `YQInvestorCombat`, `YQInvestorEnemy`, generated population/environment configuration, and `YQGeneratedEnemyRuntimeSafety`. Generated hostile sites and NPC/enemy plans are structured world records, while runtime damage/health/grounding live on curated components. Preserve the authoritative player motor and do not make generated text executable combat behavior.
