# YourQuest AI engineering system

Start with [README.md](README.md) and [project setup](Docs/PROJECT_SETUP.md). Follow [AGENTS.md](AGENTS.md), select the current goal from `Docs/ClosedBetaRoadmap_2026-09-16/GOAL_STATUS.json`, load only the relevant `AI_CONTEXT/` sheet, and use `PROMPTS/` for a bounded task packet. Review affected architecture contracts with the configured agent, verify with `UNITY_MCP_GUIDE.md`, and preserve evidence levels. A second agent or named model preset is optional unless the current session explicitly requires one.

The production architecture already includes deterministic world planning, compiled-world materialization, continuation streaming, paired profile persistence, typed LLM proposal boundaries, structured quests/dialogue, factions, combat, and UI. Existing receipts under `Docs/` remain the detailed status source; this system controls how agents change them safely.
