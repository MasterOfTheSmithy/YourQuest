## Verification and return

Verify runtime or serialized boundaries only when changed. Use the production PlaySafe scene for its affected path. Stop after three unsuccessful repairs of the same cause and return the evidence.

Return Changed, Why, Verified, and Remaining. Include source identity, specification hash, receipt path, exact PASS/FAIL/BLOCKED/NOT_VERIFIED rows, preserved contracts, and the next failing row.
