## Initial architecture map

- Origin: `YQGeneratedWorldRuntimeBuilder` prepares accepted spatial authority, builds inactive candidate terrain, applies terrain foundation and construction, persists accepted bindings, then attaches the single player-following streamer. Downstream rejection can retain canonical continuation but is explicitly NOT PLAYABLE.
- Terrain: `YQGeneratedWorldTerrain` creates a 1024 m square, 140 m vertical range, 513 height samples, centered at zero. Accepted V2 sampler and versioned seed generate rows before staged height upload.
- Streaming: `YQPlayerFollowingSemanticChunkStreamer` uses 128 m cells, grid origin -512, floor coordinates, prioritized terrain queue and separate content queue. Terrain publishes after collider synchronization, appearance runs separately, content iterators are guarded by configuration epoch.
- Heights/borders: `YQContinuousWorldCellAuthority` samples final origin Terrain, Hermite collar, then global seeded macro field. Canonical edge keys use integer grid boundaries; nine persisted height samples describe an edge. Extension terrain derives 65 samples at default settings, copies actual origin-border heights, and connects only compatible extension neighbors. Large origin-to-small tile boundary is manually sampled.
- Features: `YQContinuousWorldFeatureAuthority` computes accepted spline/terminal crossings and procedural road/river fallback. Same file owns ribbon materialization, biome paint, landmark placement and approved registry material resolution.
- Sites/settlements: accepted origin spatial sites use compiled materialization; streamed sites are deterministic landmark records resolved through existing approved palettes. Meaningful runtime functionality is not yet verified.
- Persistence: `GeneratedWorldPlanRecord.semanticChunks` owns frontier, edge, site, and delta records; `WorldStateManager.TrySave` serializes and writes full world state synchronously. Streamer currently schedules that call one frame later.
- Asset/runtime work: `YQGeneratedWorldEnvironment.BuildSemanticChunkScatterRoutine` uses palette-backed vegetation/geology with bounded quotas. Existing material repair and prefab/LOD processing need measured runtime evidence.
