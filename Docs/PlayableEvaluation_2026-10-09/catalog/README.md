# Playable evaluation candidate catalog

This catalog prepares source research and a finite test matrix for the 48 supplied URLs, the existing Qwen3.5-4B control, and three named Qwen3.5-4B variants. It is source-preparation evidence only. No model was downloaded, staged, loaded, benchmarked, or tested here; all result and test fields remain `not_run` / `unverified`.

`candidates.json` contains 52 candidates with original URLs, candidate type, checkpoint/tool identity, required companion models or files, immutable current revisions where accessible, selected artifact/runtime paths, format/quantization, adapter/training requirements, license status, 8 GB constraints, applicable YourQuest use cases, evidence URLs/text, and per-role tuning/evaluation fixture IDs. `source-snapshots.json` records source-page checks, metadata evidence, and pin status for all 52 rows. All 52 current source revisions are pinned; this is source metadata evidence, not runtime testing. Run `python Tools/PlayableEvaluation/catalog.py` to regenerate and structurally validate the JSON.

The matrix defines 33 role-specific use cases, 165 concrete fixture definitions, and 138 applicable candidate/use-case cells. Each cell names two tuning fixtures and three held-out evaluation fixtures with concrete context, input, and expected behavior; no fixture assets or runtime tests have been produced here. All 138 cells remain `not_run`.

The 8 GB budget context is the primary's reported RTX 5060 with 8,151 MiB available. This catalog contains no measured model memory claims. The combined runtime must include Unity, model weights, cache/activations, runtime overhead, and all required companion models. Toolkits and inference runtimes are not treated as model checkpoints: e.g. faster-whisper needs a separately selected Whisper checkpoint, Piper needs a chosen voice model, ML-Agents needs a trained project policy, and RVC needs a trained target voice and supporting models.
