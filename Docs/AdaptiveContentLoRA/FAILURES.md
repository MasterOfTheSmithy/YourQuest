# Failure taxonomy

| Failure | Offline check or fixture | Remaining production proof |
|---|---|---|
| Reward/rarity inflation | c01/c10/c13, ceiling and negative-trace metrics | Paired calibrated rates on larger families |
| Farming/spam | c04/c25, supplied farming flag | Real G15 diversity/outcome authority |
| Generic specialization | s27/s30 | Grounded blind interpretation review |
| Fabricated canon | c21/c22, reference membership and deferral | Prose factuality and actual canonical projections |
| Unauthorized NPC knowledge | s41/s42, knowledge subset gate | G11 knowledge provenance and real reaction receipts |
| Unsupported mechanics | c11, unknown-template rejection | Full G09 executor validation |
| Numeric hallucination | Strict schema rejects damage/cost/etc | Real template-bound execution |
| Duplicate uniqueness | c23, reservation and name collision gates | Deterministic global uniqueness/accepted-content authority |
| Hidden checklist exposure | Output pattern checks | Diegetic human review beyond obvious patterns |
| Constant player worship | Restrained local reaction fixtures | Blind NPC response review and knowledge scope |
| Combat bias | c14/c15/c16 and noncombat slices | Supported peaceful destinations and comparable recall |
| Prose-only reward | Propose requires supplied destination | Actual committed consequence; presentation-only title explicitly labelled |
| Generic/repeated names | Lexical warnings, counterfactual names, review pack | Repetition metrics, semantic collisions and memorability review |
| Choice/lineage retcon | c18/c19/c20, parent/lineage checks | Persisted accepted/declined choices and later hooks |
| Premature grant | Proposal-only state and grant-language checks | Announce only after deterministic commit receipt |
| Accepted identity regenerated | Demo E specification | Model-off reload equality |
| Adapter destabilizes other roles | No runtime mutation | Same stable model canaries for origin/world/NPC/quest/dialogue tasks |
| Resource/lifecycle harm | Audit identifies existing safeguards | Startup, inference, frame, memory and cancellation measurements |

Reject or revise on any accepted authority violation, missing causal-quality improvement, unbounded rarity, regression of accepted content, or failure to fit measured budgets. Record raw model failures separately from successful validator rejection. A failed experiment with trustworthy evidence is acceptable; training completion alone is never ADOPT.
